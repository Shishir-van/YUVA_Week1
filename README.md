# Week 1: Python for Machine Learning and Data Preprocessing

## Objective
To understand and perform data cleaning, exploratory data analysis (EDA), categorical encoding, feature selection, and normalization using Python.

## Dataset
The project uses the Titanic dataset available through Seaborn Library.

## Tech Stack
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Jupyter Notebook

## Tasks Completed
- Loaded and inspected the dataset.
- Checked data types, descriptive statistics, and missing values.
- Handled missing values using median and mode.
- Identified and removed exact duplicate rows.
- Explored distributions and potential outliers using visualizations.
- Calculated descriptive statistics and correlation.
- Encoded categorical features using one-hot encoding.
- Applied Min-Max normalization to input features.
- Exported the cleaned dataset, normalized features, and target variable as CSV files.

## Project Files
- `week1_preprocessing.ipynb` — preprocessing notebook.
- `titanic_cleaned.csv` — cleaned dataset.
- `titanic_preprocessed_features.csv` — normalized input features.
- `titanic_target.csv` — target variable.

## How to run 
1. Install Python and Jupyter Notebook.
2. Install the required libraries: `pandas`, `numpy`, `matplotlib`, and `seaborn`.
3. Open `week1_preprocessing.ipynb` in Jupyter Notebook.
4. Run the cells from top to bottom.

## Outcome
This project demonstrates fundamental data preprocessing and EDA techniques used to prepare tabular data for machine learning.
